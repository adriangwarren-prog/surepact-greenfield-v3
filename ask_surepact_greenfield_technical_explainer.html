1. Greenfield Architecture Overview

The Ask SurePact feature provides a natural language executive reporting and analytics synthesis engine within the SurePact Greenfield platform. Users enter arbitrary analytical queries in plain text, and the system synthesizes live database state into a structured executive report containing:

  • AI Executive Summary: High-level text synthesis with AUD amounts and strategic advice.
  • KPI Ribbon: Grid of metric badges (e.g. Total Active Awarded Value, Compliance Score).
  • Multi-Mode Dynamic Visualization: SVG Bar charts, Donut/Pie charts, Line graphs, and Data Tables.
  • Interactive Audit Table: Filterable data rows with CSV & PDF export capabilities.

2. Backend Implementation (Node.js / Express / TypeScript)

The backend component is divided into two parts: the Express route handler server/src/index.ts and the AI query processing service server/src/askSurepactService.ts.

2.1 Express Endpoint & Prisma Context Retrieval

When the client POSTs to /api/analytics/ask, the route fetches active database context across 5 core entities using Prisma ORM:

EXPRESS ROUTE HANDLERserver/src/index.ts
// POST /api/analytics/ask - Ask SurePact AI natural language reporting engine
app.post('/api/analytics/ask', async (req, res) => {
  try {
    const { prompt } = req.body;
    if (!prompt) {
      return res.status(400).json({ success: false, error: 'Prompt is required' });
    }

    // Query live organizational context via Prisma ORM
    const grants = await db.grant.findMany({
      include: {
        riskAssessment: true,
        contracts: true,
        projectMappings: true,
        businessUnit: true
      }
    });

    const tasks = await db.milestoneTask.findMany({
      include: { assignedToUser: true, grant: true }
    });

    const transactions = await db.transaction.findMany();
    const fundingBodies = await db.fundingBody.findMany();
    const businessUnits = await db.businessUnit.findMany();

    // Call async Gemini AI service
    const reportPayload = await processAskSurePactQueryAsync(
      prompt,
      grants,
      tasks,
      transactions,
      fundingBodies,
      businessUnits
    );

    res.json({ success: true, data: reportPayload });
  } catch (error: any) {
    res.status(500).json({ success: false, error: error.message });
  }
});

2.2 Gemini API Prompting & Strict JSON Schema Enforcement

In askSurepactService.ts, the backend constructs a summary context object and sends a system prompt to Google GenAI REST API (using gemini-2.0-flash with gemini-1.5-flash fallback) enforcing responseMimeType: "application/json".

GEMINI AI PROCESSING SERVICEserver/src/askSurepactService.ts
export async function processAskSurePactQueryAsync(
  prompt: string,
  rawGrants: any[] = [],
  rawTasks: any[] = [],
  rawTransactions: any[] = [],
  rawFundingBodies: any[] = [],
  rawBusinessUnits: any[] = []
): Promise<AskSurePactReportResponse> {
  const apiKey = process.env.GEMINI_API_KEY;

  if (apiKey) {
    try {
      // 1. Compact Context Summarization
      const summaryContext = {
        grantsCount: rawGrants.length,
        grantsSample: rawGrants.slice(0, 10).map((g: any) => ({
          title: g.title,
          funder: g.funderName,
          value: g.totalFundingValue || g.amountRequested || 0,
          status: g.status,
          closeDate: g.closeDate,
          riskRating: g.riskAssessment?.overallRiskRating || 'UNASSESSED'
        })),
        tasksCount: rawTasks.length,
        tasksOverdue: rawTasks.filter((t: any) => t.dueDate && new Date(t.dueDate) < new Date()).length
      };

      // 2. Strict Schema System Instruction
      const aiPrompt = `You are SurePact AI, an executive grant analytics intelligence engine for Australian Non-Profits.
The user asked: "${prompt}"

Current Database Context Summary:
${JSON.stringify(summaryContext, null, 2)}

Generate a highly structured executive analytical report matching this exact JSON schema:
{
  "queryTitle": "Concise Executive Report Title",
  "queryIntentText": "Clear description of analyzed criteria",
  "executiveSummary": "2-3 sentences of deep executive synthesis with specific AUD amounts and strategic advice.",
  "metrics": [
    { "label": "Metric Name", "value": "$AUD Value or %", "subtext": "Contextual subtext", "trend": "up" }
  ],
  "chartType": "bar",
  "chartData": [
    { "label": "Item Name", "value": 150000, "category": "Funder/BU" }
  ],
  "tableHeaders": ["Grant Title", "Funder", "Status", "Value", "Close Date"],
  "tableRows": [
    { "Grant Title": "Sample", "Funder": "Sample Funder", "Status": "AWARDED", "Value": "$500,000", "Close Date": "30/11/2026" }
  ]
}

Return ONLY raw valid JSON. Do not put markdown code fences.`;

      // 3. Invoke Gemini REST API with JSON Mode
      let apiURL = `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent?key=${apiKey}`;
      let response = await fetch(apiURL, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          contents: [{ parts: [{ text: aiPrompt }] }],
          generationConfig: { responseMimeType: 'application/json' }
        })
      });

      // Fallback endpoint check
      if (!response.ok) {
        apiURL = `https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=${apiKey}`;
        response = await fetch(apiURL, {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({
            contents: [{ parts: [{ text: aiPrompt }] }],
            generationConfig: { responseMimeType: 'application/json' }
          })
        });
      }

      if (response.ok) {
        const result: any = await response.json();
        const text = result.candidates?.[0]?.content?.parts?.[0]?.text;
        if (text) {
          const parsed = JSON.parse(text.trim());
          if (parsed.queryTitle && parsed.executiveSummary && Array.isArray(parsed.metrics)) {
            return {
              queryTitle: parsed.queryTitle,
              queryIntentText: parsed.queryIntentText || `AI Synthesized Insights for "${prompt}"`,
              executiveSummary: parsed.executiveSummary,
              metrics: parsed.metrics,
              chartType: parsed.chartType || 'bar',
              chartData: parsed.chartData || [],
              tableHeaders: parsed.tableHeaders || ['Grant Title', 'Funder', 'Status', 'Value'],
              tableRows: parsed.tableRows || [],
              csvData: '',
              appliedFilters: { Engine: 'Gemini 2.0 Flash LLM', Query: prompt },
              recordCount: (parsed.tableRows || []).length
            };
          }
        }
      }
    } catch (e) {
      console.warn('[Ask SurePact] Gemini AI generation fallback to pattern engine:', e);
    }
  }

  // 4. Fallback Synchronous Pattern Engine
  return processAskSurePactQuery(prompt, rawGrants, rawTasks, rawTransactions, rawFundingBodies, rawBusinessUnits);
}

3. Frontend UI Component Architecture (React / TypeScript)

The frontend is structured into modular React components inside client/src/components/.

3.1 Reporter Component client/src/components/AskSurePactReporter.tsx

Manages natural language input, handles API calls to /api/analytics/ask, renders executive summary cards, KPI metric grids, interactive search tables, and triggers CSV/PDF exports.

3.2 Dynamic Chart Switcher client/src/components/DynamicChartRenderer.tsx

A standalone visualization component that dynamically converts chartData into 4 distinct views based on user selection:

  • 📊 Bar Chart View: Horizontal SVG progress bars with HSL gradients and value tooltips.
  • 🍩 Donut / Pie View: Custom SVG doughnut segments calculated using arc trigonometry (A 70 70 0 ...) with interactive legend.
  • 📈 Line Curve View: SVG polyline trend graph with gradient fills (polygon) and interactive plot nodes.
  • 📋 Data Table View: Clean tabular metric layout.
MULTI-MODE CHART COMPONENTDynamicChartRenderer.tsx
export const DynamicChartRenderer: React.FC<DynamicChartRendererProps> = ({
  data = [],
  title = 'Data Visualization',
  subtitle = 'Interactive Metric Analysis',
  defaultChartType = 'bar'
}) => {
  const [chartType, setChartType] = useState<'bar' | 'pie' | 'line' | 'table'>(
    defaultChartType === 'kpi' ? 'bar' : defaultChartType
  );

  return (
    <div className="panel-card" style={{ padding: '24px' }}>
      {/* Mode Switcher Toolbar */}
      <div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center' }}>
        <h4>{title}</h4>
        <div className="toolbar">
          <button onClick={() => setChartType('bar')}>📊 Bar</button>
          <button onClick={() => setChartType('pie')}>🍩 Donut</button>
          <button onClick={() => setChartType('line')}>📈 Line</button>
          <button onClick={() => setChartType('table')}>📋 Table</button>
        </div>
      </div>

      {/* Render Active View */}
      {chartType === 'bar' && renderBarChart()}
      {chartType === 'pie' && renderDonutChart()}
      {chartType === 'line' && renderLineChart()}
      {chartType === 'table' && renderTable()}
    </div>
  );
};

3.3 PDF Executive Exporter client/src/services/AnalyticsPdfExporter.ts

Generates an executive-styled HTML printable document containing SurePact corporate branding, summary text, KPI grids, and formatted data tables, triggering window.print() for clean PDF generation without canvas taint errors.

4. Architectural Benefits of This Design

⚡ Ultra-Fast Development

Decoupling AnalyticsHub, AskSurePactReporter, and DynamicChartRenderer out of monolithic App.tsx reduced file sizes from 12,500+ lines to ~200-350 lines per component, ensuring clean maintainability.

🛡️ Zero Downtime Resilience

If the Gemini API key is missing or quota is exceeded, processAskSurePactQueryAsync seamlessly falls back to the local synchronous pattern engine without throwing 500 errors to the client.
