Team Collaboration Blueprint

SurePact Team Git & AI Workflow Guide

Enabling Founder & Head of Product to build and test features simultaneously using Antigravity & Git Feature Branches

🛠️
Section 1: Initial Machine Setup for Head of Product
1
Install Software Prerequisites
Download and install Antigravity Client and Node.js (v18+). Verify default App Data folder exists:
C:\Users\<YourUsername>\.gemini\antigravity
2
Clone the GitHub Repository
Open Terminal / PowerShell and clone the codebase:
mkdir C:\Users\$env:USERNAME\projects
cd C:\Users\$env:USERNAME\projects
git clone https://github.com/adriangwarren-prog/surepact-greenfield.git
cd surepact-greenfield
3
Import Conversation History & Context
To give your local Antigravity instance full context of all past decisions and architecture:
  1. Start a new chat session in Antigravity to create a folder under \.gemini\antigravity\brain\<new-id>\.
  2. Copy the exported transcript.jsonl and transcript_full.jsonl files.
  3. Paste and overwrite them into \.gemini\antigravity\brain\<new-id>\.system_generated\logs\.
  4. Re-open Antigravity to load full history into your agent.
4
Install & Launch Local Application
Run standard install commands to spin up the local server and client:
# Terminal 1: Backend API
cd server
npm install
npx prisma db push
npm run dev

# Terminal 2: Frontend Client
cd client
npm install
npm run dev
🌿
Section 2: Daily 4-Step Feature Branch Loop

Never edit directly on main. Use this isolated feature loop to build and test safely:

1
Create Branch
Tell Antigravity:
"Create branch feature/product-name"
2
Prompt Agent
Prompt Antigravity as normal to build your feature in isolation.
3
Push & Preview
Tell Antigravity:
"Push to git".
Vercel generates preview link.
4
Sync & Merge
Tell Antigravity:
"Pull main & resolve conflicts" before merging.
🤖
Section 3: Antigravity Session Startup Prompt

Copy and paste this text into your Antigravity chat whenever starting a new working session:

Please initialize our session by inspecting recent git commits (`git log -n 5`) and reviewing the latest walkthrough artifact. Confirm what branch we are on and summarize the latest updates made across the team before we begin.
